# Zareef-hossain.github.io

Personal Research &amp; Engineering Portfolio of Ifreet Zareef Hossain — https://zareef-hossain.github.io/

Built with React, TypeScript, Vite, Tailwind CSS v4 and Motion; deployed to GitHub Pages via GitHub Actions.

```bash
npm install
npm run dev       # local development
npm run build     # production build → dist/
npm run preview   # serve the production build
```

Portfolio content lives in `src/content/`. See `CLAUDE.md` for architecture, conventions and roadmap.
